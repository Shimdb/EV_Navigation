# Android Frontend

## 담당자
정남훈

## 개발 환경
- Android Studio
- Kotlin
- XML
- RecyclerView

## 구현 기능

### 1. 로그인
- 아이디 및 비밀번호 입력 화면 구현
- 로그인 버튼 구현
- 로그인 후 메인 화면으로 이동
- 회원가입 화면 이동 기능 구현

### 2. 회원가입
- 회원가입 화면 UI 구현
- 로그인 화면과 연결

### 3. 충전소 목록
- RecyclerView를 이용한 충전소 목록 구현
- 충전소 이름 및 충전 방식 표시
- 충전소 선택 시 상세 화면으로 이동

### 4. 충전소 검색
- 검색창 구현
- 충전소 이름을 기준으로 검색
- 검색 결과에 따라 목록 필터링

### 5. 충전소 상세 정보
- 선택한 충전소의 이름 및 충전 방식 표시
- 상세 화면 UI 구현

### 6. 즐겨찾기
- 즐겨찾기 버튼 UI 구현
- 버튼 클릭 시 즐겨찾기 추가 안내
- 현재는 프론트엔드 UI 단계로 구현

## 주요 코드

### MainActivity.kt
충전소 목록을 표시하고 검색 기능을 처리합니다.

### Station.kt
충전소 정보를 저장하는 데이터 클래스입니다.

### StationAdapter.kt
충전소 데이터를 RecyclerView에 표시하고 충전소 선택 시 상세 화면으로 이동합니다.

### StationDetailActivity.kt
선택한 충전소의 상세 정보를 표시하고 즐겨찾기 버튼을 제공합니다.

### LoginActivity.kt
로그인 화면을 구성하고 메인 화면 및 회원가입 화면으로 이동합니다.
